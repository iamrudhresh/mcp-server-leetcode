System Design

Transport & Execution Architecture

stdio transport Default for Desktop AI

Runs as a lightweight subprocess spawned directly by your desktop client. Standard input & output carry structured JSON-RPC messages, with application logging strictly routed to stderr.

  • ✓ Zero port collisions or firewall issues
  • ✓ Automatic process lifecycle managed by client
  • ✓ Token redaction in logs to prevent leaks
Streamable HTTP For Web & Docker

Hosts a standalone HTTP server implementing the MCP Streamable HTTP protocol with Server-Sent Events (SSE) and stateful session routing for distributed environments.

  • ✓ Multi-client shared server via Docker
  • ✓ Stateful session isolation with UUID tokens
  • ✓ Graceful shutdown via SIGTERM handlers
